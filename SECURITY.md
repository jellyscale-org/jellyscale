# Security policy

Please don't open a public issue for a vulnerability. Report it privately through [GitHub security advisories](https://github.com/jellyscale-org/jellyscale/security/advisories/new).

Include the affected version or commit, how to reproduce it, and the impact. We'll acknowledge reports as soon as we can and credit you unless you'd rather we didn't.

jellyscale is pre-release, so only the latest `main` is supported.
