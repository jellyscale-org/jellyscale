# compat

Recorded observations of another media server (Jellyfin 12.4) and its web client, made while the earlier jellyscale served that server's API.

**They are not requirements.** jellyscale no longer follows that API or its behaviour (D-20261127-new-software, D-20261128-no-jellyfin-features). They stay only because tests of the code still in the tree read them, including the device statement most conversion tests use. Each goes with the code that reads it.

What players were seen to do, where it still matters, is restated in [docs/players.md](../docs/players.md). Don't add to this directory.
